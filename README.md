# ピンポンキング

ブラウザで遊べる、一人用のCPU対戦ピンポンゲームです。

**プレイ:** https://kagoya.github.io/ppking/

## 操作

- ↑↓キー、W・S、マウス、タッチで左側のバーを移動
- Spaceで開始・一時停止（ボタンでも操作可能）
- 吸着したボールは3キーか発射ボタンで発射
- 難易度は3段階。効果音はON/OFF切り替え可能

## ルール

- アイテムの的は5〜15秒のランダム間隔で1個ずつ出現し、最大5個まで表示
- 的の表示時間は50〜100秒のランダム
- ボールで的に当てると、その場所から最後に打った側へアイテムが横方向に移動
- バーで受け止めると獲得し、その場で技が自動発動
- 技はバー延長（10秒）、ボール追加（2個、球の上限5個）、吸着の3種類
- ボールを取り逃すごとに相手に1点。球が残っている間はラリー続行
- 最後の球を取り逃すとラリー終了。7点以上で得点が高い側が勝利。同点なら続行

## ローカルで遊ぶ

`index.html`をブラウザで開けば遊べます。ビルドや依存ライブラリは不要です。

## GitHub Pages

`main`ブランチのルートディレクトリをGitHub Pagesで公開しています。
